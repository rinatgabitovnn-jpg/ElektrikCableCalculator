# Веб-версия калькулятора

Мобильная версия калькулятора для Safari и других браузеров. Отдельная от Android APK, расчётная логика перенесена из приложения.

## Локальный просмотр
Откройте index.html в браузере. Для установки PWA и автономной работы после первого посещения нужен HTTPS-хостинг (например, GitHub Pages).

## iPhone
После публикации откройте HTTPS-адрес в Safari → «Поделиться» → «На экран Домой».

## Важно
Расчёт сохраняет ограничения Android-версии: колонка B2 и поправочные коэффициенты; падение напряжения считается упрощённо; автомат проверяется только по Ib ≤ In ≤ Iz. Подробности приведены в самом калькуляторе.
