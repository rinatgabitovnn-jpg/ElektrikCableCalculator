# Электрик — расчёт сечения ВВГнг(А)-LS в гофре

Android-проект Kotlin + Jetpack Compose. Приложение работает офлайн.

## Сборка APK
Откройте проект в Android Studio с JDK 17, Android SDK Platform 35 и Gradle 8.9. Версия приложения в проекте — 1.4. Дождитесь синхронизации и выберите:
**Build → Build Bundle(s) / APK(s) → Build APK(s)**.

Альтернатива: загрузите проект в GitHub и запустите workflow **Build Android APK** во вкладке Actions. Результат сборки `app-debug.apk` будет доступен как artifact.

## Методика в этой версии
- Только медный многожильный ВВГнг(А)-LS с ПВХ-изоляцией.
- Открытая прокладка в гофрированной трубе, закреплённой непосредственно на поверхности. Базовая модель B2 применяется только при условиях таблицы A.52.3, позиция 5; для потолочной полости/подвесного потолка/теплоизоляции метод выбирается отдельно.
- Таблицы B.52.2 (2 нагруженные жилы) и B.52.4 (3 нагруженные жилы), графа B2.
- Температурная поправка B.52.14.
- Групповой коэффициент B.52.17, позиция 1; пользователь отдельно отмечает, проложены ли гофры тесной группой. При зазоре более 2 наружных диаметров коэффициент не применяется.
- Сечение выбирается по большему из минимумов по нагреву и предварительному падению напряжения.
- Однофазный/трёхфазный расчёт, ввод А или кВт, cos φ, длина, температура, группировка, ручная/автоматическая проверка номинала автомата.

## Нормативные документы
- ГОСТ Р 50571.5.52-2011: таблица A.52.3, позиция 5 (труба на стене/поверхности), таблицы B.52.2 и B.52.4 (B2), B.52.14 (температура), B.52.17 (группировка).
- ГОСТ 31996-2012 с Изменением № 1: обозначение кабеля, материалы жил и исполнения нг(A)-LS.

## Границы применимости — обязательно
Метод B2 в ГОСТ Р 50571.5.52-2011 описан как многожильный кабель в трубе на деревянной/кирпичной стене или поверхности на малом расстоянии от неё. Это не универсальный метод для любой потолочной полости, теплоизоляции, закрытого короба, нескольких гофр в замкнутом пространстве или иной конструкции. Для теплоизолированной стены указан метод A2. Для подвесного потолка и полостей конструкций следует отдельно определить способ по таблицам A.52.2/A.52.3 и оценить температуру в верхней части вертикальных трасс.

Групповой коэффициент позиции 1 таблицы B.52.17 предназначен для однотипных одинаково нагруженных цепей, сгруппированных в воздухе, на поверхности, замоноличенно или в оболочке. Для иных геометрий/способов прокладки нужны другие позиции или индивидуальный расчёт.

Падение напряжения — предварительная оценка по активному сопротивлению нагретой меди без реактивной составляющей. Проверка автомата ограничена Ib ≤ In ≤ Iz. Не выполнены проверки I₂, петли «фаза-ноль», тока КЗ, времени отключения, термической стойкости и характеристик конкретного аппарата. Приложение не является заключением о полном соответствии ПУЭ/ГОСТ и не заменяет проектную проверку.
